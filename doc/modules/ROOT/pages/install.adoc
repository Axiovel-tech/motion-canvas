= Software installation
:imagesdir: ../assets/images
:experimental:

*Motion Canvas* is a platform independent tool, just like
Blender. The installation procedure is the same for Linux, macOS and Windows.
Please follow the steps below.

== Installation

=== 1. Check hardware requirements

We suggest following the https://www.blender.org/download/requirements/[official Blender recommendation] for choosing your computer on which you want to run Blender and *Motion Canvas*.

An additional requirement is that *Motion Canvas* needs to communicate with a trajectory backend for certain tasks such as planning transitions or creating exports in the compiled (`.skyc`) show format. By default this is the local *Axio trajectory engine* running on your own machine, so no Internet connection is required for these tasks; if you choose to use the online community server instead, you need an active Internet connection. You may use the software without a backend, but the functions that require one will not be available until it is reachable again.

=== 2. Install Blender

There are many Blender versions available. We aim for compatibility with the https://www.blender.org/download/lts/[latest Long Term Support (LTS) release]. This is version 4.5 at the time of writing. If you are unsure, check the version number of the https://www.blender.org/download/lts/[latest Long Term Support (LTS) release] on the Blender site.

=== 3. Install Motion Canvas

*Motion Canvas* is installed as a single `.zip` file. You can obtain it in either of two ways:

* Download it from the releases page of the https://github.com/Axiovel-tech/motion-canvas[Motion Canvas GitHub repository].
* Build it yourself from a checkout of the repository by running `etc/scripts/create_blender_dist.sh`; the resulting `.zip` file is placed in the `dist/` folder.

Once you have the `.zip` file on your computer, follow the instructions below.

WARNING: Safari on macOS automatically unzips all `.zip` files by default, which will prevent you from selecting the `.zip` file itself when installing the plugin. If you are using Safari on macOS, hold down the kbd:[Option] key when clicking on the download link to prevent this from happening, or turn off the unzipping of "safe" files permanently in menu:Safari[Preferences > General].

image::install_blender_addons.jpg[Install Blender Add-ons]

1. Open Blender and go to Edit -> Preferences -> Add-ons.

2. Select btn:[Install from Disk...] from the dropdown menu in the top right corner.

3. In the popup window select the *Motion Canvas* `.zip` file that you have downloaded or built previously, and press kbd:[Enter].

4. Once installed, activate the "Motion Canvas" add-on by clicking on the checkbox next to this item in the add-on list (you may need to scroll down to find the "Motion Canvas" item).

5. Setup add-on preferences by pressing the btn:[>] button on the left side of the "Motion Canvas" add-on item. Note that generally you do not need to change any settings; the add-on uses the local *Axio trajectory engine* by default:

    API key:: If you have received an API key for communicating with a remote backend server, paste it here (by default you do not have to touch this setting).

    Server URL:: Enter the URL of a dedicated backend server if you are using one (by default you do not have to touch this setting; when left empty, the local *Axio trajectory engine* is used, change only if you know what you are doing).

    Use Axio engine (local):: Press this button to use the local *Axio trajectory engine* running on your own machine. This is the default backend.

    Use Skybrush community server:: Press this button to use the online community server instead of the local engine. This action will fill the btn:[Server URL] field automatically. The community server is a free third-party service but it might be limited in drone number, execution time or available features; some features described in this manual are only available with a licensed backend.

    Enable experimental features:: Enable this checkbox if you are open to experiment with the latest features of *Motion Canvas*.

=== 4. Enable Online Access in Blender

Starting from Blender 4.2, the preferences dialog provides an option where the user can explicitly indicate that they wish to allow (or deny) access to online resources. *Motion Canvas* uses a network resource (the local *Axio trajectory engine* by default, or the online community server) to calculate transitions, decompose formations, plan takeoffs and landings and export the show into various file formats. If you want to use the full capabilities of the add-on, you need to enable online access if you are running Blender 4.2 or later. Earlier versions of Blender are not affected.

To turn on online access, open Blender and go to Edit -> Preferences -> System, scroll down to the "Network" section and then tick the "Allow Online Access" checkbox.

=== 5. Setup network timeout in Blender

If you use large fleets and/or long and fine-grained shows, make sure that the "Network timeout" setting right below the "Allow Online Access" checkbox is large enough to handle your requests to the backend server.

The longest action is usually the show export. During export, most time is taken by the sampling of your show within Blender to form the input of the requests towards the backend. Even though this procedure is _not_ part of the request time, with large shows you may run into cases where you do need more processing time than the default 10 seconds. If such timeout occurs, raise the value as convenient.

=== 6. Install the Axio trajectory engine

*Motion Canvas* talks to the *Axio trajectory engine* (`axio-traj-rest`) at `http://localhost:8000` by default. Make sure the engine is running on your machine before using features that need a backend (transitions, takeoff and landing planning, exports). Refer to the Axio trajectory engine documentation for how to launch it; you can override its address with the `AXIO_TRAJ_SERVER_URL` environment variable if it runs elsewhere.

If you prefer not to run a local engine, you can point the add-on at the online community server instead using the btn:[Use Skybrush community server] button in the add-on preferences (see above), keeping in mind its limitations.

== Installing updates

*Motion Canvas* consists of multiple modules that are interpreted by the Python interpreter built into Blender. To perform an upgrade of the add-on, the previous version needs to be unloaded completely before the new version is installed. Due to how Python's module system works, this is very hard to do without unloading the plugin manually. Therefore, the preferred sequence to update the add-on is as follows:

1. Deactivate the add-on in Edit -> Preferences -> Add-ons by unticking the checkbox in front of the btn:[Motion Canvas] add-on.

2. Install the new version of the add-on using the same procedure as outlined above.

3. Exit Blender.

4. Restart Blender.

5. Activate the add-on again in Edit -> Preferences -> Add-ons.

NOTE: If the update still fails after following the steps outlined above, try to completely uninstall the old add-on first manually (as described below) and then re-install the new one from scratch.

== Uninstallation

If you decide to uninstall *Motion Canvas* for any reason, you have to do it manually. Removing the add-on from Blender's add-on manager is possible, but it will not remove all files related to *Motion Canvas*. The full, manual process is as follows:

1. Deactivate the add-on first in Blender's add-on manager.
2. Open the file manager of your operating system and navigate to the folder containing the Blender add-ons. Refer to https://docs.blender.org/manual/en/latest/advanced/blender_directory_layout.html[Blender's documentation] to find the add-ons folder.
3. Remove the file named `ui_skybrush_studio.py`.
4. Also remove the `skybrush` folder within the `vendor` folder.
