= Overview
:imagesdir: ../assets/images

*Motion Canvas* is part of the https://axiovel.com[*Axiovel*] suite, an integrated software solution for the design, visualization, testing and delivery of both indoor and outdoor drone light shows. The suite is built on a rock-solid platform-independent architecture and a clean and intuitive user interface.

The https://axiovel.com[*Axiovel*] suite is modular, consisting of the following components, each of which may be operated on its own or as part of the whole suite:

* Design and validation:
** *Motion Canvas* - drone show designer framework frontend, integrated into Blender
** *Axio trajectory engine* - drone show designer framework backend
** *Skybrush Viewer* - 3D drone show visualiser for testing and presentation purposes
* Execution:
** *Axio Control* - drone show management and fleet control framework frontend
** *Axio Server* - drone show management and fleet control framework backend
** *Show firmware* - drone show firmware onboard the drones

In this manual our focus is on *Motion Canvas*, an implementation of the show design modules and functions in https://www.blender.org/[Blender], an open-source 3D creation suite.

If you are interested in working with *Motion Canvas* but you prefer to use another animation software, please mailto:{contact-email}[contact us].
